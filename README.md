#PublicUtilityComplaintSystem

Problem Statement: Design and implement a Java console-based Complaint Management System 
that allows users to register complaints, assign technicians, update complaint status, 
and maintain complaint history. The system should demonstrate object-oriented programming
concepts such as encapsulation, modular design, and exception handling while managing complaints 
efficiently through console interaction.

How to compile and run: Clone the repository and move into the project folder: git clone https://github.com/your-username/
ComplaintManagementSystem.git cd ComplaintManagementSystem. Compile and run the project :javac com/wipro/ucms/**/*.java
java com.wipro.ucms.main.Main. This will start the console-based Complaint Management System.
